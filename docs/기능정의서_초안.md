# ThermaVita Hydro 제품 연동 사용 가이드 앱 — 기능정의서 (초안)

- **과업명**: ThermaVita Hydro 제품 연동 사용 가이드 애플리케이션 개발
- **발주자**: 주식회사 부티릭스 / **수행사**: 주식회사 에이콘랩
- **플랫폼**: 반응형 웹앱 (모바일/PC 브라우저 대응)
- **대상 사용자**: 스마트팜·수경재배 농가 사용자 / 관리자(부티릭스)

> **기준 문서 우선순위**: 본 기능정의서의 요건은 **과업지시서를 1차 기준**으로 작성함. 부티릭스 사업계획서(2026년 지원사업) 등 기타 자료는 배경 이해를 돕는 **참고 자료**로만 사용하며, 과업지시서와 내용이 다르거나 사업계획서에만 있는 세부사항은 확정 근거가 아닌 "참고·확인 필요" 정보로 표시함.

> ⚠ **제품 정의 관련 작업 가정**: 과업지시서는 "ThermaVita Hydro(수경 양액 시스템용 시제품)"으로 명시함(이를 기준으로 채택). 참고로 부티릭스 사업계획서에는 "ThermaVita"로만 기재되어 있고 "Hydro"라는 표기는 없어, 동일 제품인지는 별도 확인 필요(4항 참조). 아래 제품 특성(여과·정제, pH/EC 안정성 등)은 사업계획서에도 없는 내용으로, 서비스 설계를 위한 작업 가정이며 **정식 제품 스펙은 부티릭스 확인 후 확정 필요**.

### 0. 제품 정의 (작업 가정)

**ThermaVita Hydro** — 수경·양액 시스템 특화 유산균 발효 유래 바이오스티뮬런트 (단일 제품)

| 항목 | 내용 |
|------|------|
| 제형 특성 | **여과·정제 처리** (침전 방지, 자동화 설비 노즐막힘 방지), **pH/EC 안정성** 확보된 제형 |
| 적용 방식 | 양액 관주·순환 공급, **자동 살포(디스펜서/점적 장비) 연동** |
| 재배 환경 | 수경·양액 시스템(스마트팜) |

## 2. 기능 상세

### 2.0 홈 / 공통

> **홈 화면 재정의**: 홈은 "제품 스캔 유도 화면(1회성)"도, "내 작물 리스트만"도 아니라 **둘을 함께 고정 배치**. 과업지시서상 이 앱의 정체성이 "제품 연동 사용 가이드"이므로, 등록작물 유무와 무관하게 **제품 스캔 진입점은 항상 화면 최상단에 고정 노출**하고, 그 아래에 등록작물 리스트를 보여줌 (리스트가 없으면 스캔 카드만 보이는 자연스러운 빈 상태). 마이페이지(CM-02)는 계정·재배환경 같은 저빈도 설정 전용으로 역할 축소.

| ID | 기능명 | 설명 | 우선순위 |
|----|--------|------|----------|
| CM-01 | 공지사항 조회 | 관리자(AD-04)가 등록한 공지사항을 홈 화면 **최상단** 배너로 노출·목록/상세 조회 (비로그인 사용자도 열람 가능). 일반 공지 기준이며, 안전·리콜 등 긴급 공지는 별도 경고색 배너로 예외 처리(향후 정의) | 필수 |
| HM-01 | 등록 작물 목록 (홈) | 사용자가 등록한 작물×적용방법 카드 리스트, 각 카드에 다음 관주일정 미리보기 표시. 등록 작물이 없으면 리스트 영역 자체가 생략 | 필수 |
| HM-02 | 제품 카드 / 새 작물 등록 진입 | 홈 화면에서 공지사항 다음으로 고정 노출되는 제품 카드(ThermaVita Hydro, 제품 사진). "제품 정보 보기"(PL-04 이동), "새로 스캔하기"(PL-01/02 플로우 진입) 버튼 포함 | 필수 |
| HM-03 | 작물 상세 | 등록 작물 카드 클릭 시 진입. 해당 작물의 사용법 통합 내용(GD-03~08) 재열람 + 다음 일정 미리보기 + 최근 이력 요약 표시 | 필수 |
| HM-04 | 작물 상세 → 일정/이력/폭염안내 바로가기 | 작물 상세 화면에서 "일정 등록"(일정 없을 때)/"일정 보기"(있을 때, MG-02 진입, 작물 사전입력) 버튼 **조건 분기**, "이력 입력"(MG-04 진입, 작물 사전입력), "폭염 대응 시점 안내" 버튼 | 필수 |
| GD-11 | 내 작물로 등록 | 사용법 통합화면(GD-03~08 열람 후) 하단 CTA. 선택한 작물×적용방법을 HM-01 목록에 저장. **비로그인 상태면 로그인 화면(MG-01)으로 유도 후, 로그인 완료 시 원래 화면으로 복귀해 등록 완료** | 필수 |
| GD-00 | 가이드 홈 | "가이드" 탭 랜딩 화면. 등록 없이 둘러보는 취지 안내 + 작물 그리드 → GD-01(작물선택) 이하 흐름과 동일하게 진행 | 필수 |
| CM-02 | 마이페이지 허브 | 프로필 카드(사용자 정보) + 메뉴 목록: 재배환경 관리, 공지사항 전체보기, 이용약관·개인정보처리방침, 로그아웃, 회원탈퇴. **등록 작물 목록은 여기 없음 — 홈(HM-01)으로 이동** | 필수 |

### 2.2 사용 가이드

> **설계 원칙**: 과업지시서의 "재배방식"은 문맥상(예시가 "관주 시") 토양/수경 구분이 아니라 **적용방법**을 뜻하는 것으로 해석. 본 서비스는 수경 양액 시스템 전용이므로, 적용방법은 **① 관주식 양액공급 ② 엽면살포** 2가지로 한정.
>
> **화면 구성 원칙**: 선택된 작물×적용방법에 대한 GD-03~08 정보는 하나의 "사용법 세트"이므로, 화면을 쪼개서 클릭해 넘기지 않고 **한 화면에서 스크롤로 이어 보여줌** (희석배수→사용법→[관주식: 양액혼화→EC·pH→순환주기] 또는 [엽면살포: 살포방법→살포주기]). GD-09(폭염대응)·GD-10(자동살포설비)처럼 주제가 다른 콘텐츠만 화면 하단에 **버튼**으로 분리 진입.

| ID | 기능명 | 설명 | 적용경로 | 화면 내 위치 |
|----|--------|------|----------|----------|
| GD-01 | 작물 선택 | 작물 종류 선택 | 공통 | 별도 화면 |
| GD-02 | 적용방법 선택 | 관주식 양액공급 / 엽면살포 중 선택 | 공통 | 별도 화면 |
| GD-03 | 희석배수·기본 사용법 안내 | 선택된 작물×적용방법 조합의 희석배수, 기본 사용법 표시 (방법별 수치 상이) | 공통(값은 분기) | 결과화면 상단 |
| GD-04 | 양액 혼화 가이드 | 기존 양액에 섞는 절차(혼화 순서·비율) 안내 | 관주식 전용 | 결과화면 내 섹션 |
| GD-05 | EC·pH 관리 범위 안내 | 양액 자체의 권장 EC/pH 범위 표시 | 관주식 전용 | 결과화면 내 섹션 |
| GD-06 | 순환·공급 주기 안내 | 주 1~2회 등 순환식 시스템의 공급 주기, 유의사항 | 관주식 전용 | 결과화면 내 섹션 |
| GD-07 | 살포 방법 안내 | 분무 기법(부위, 시간대 등) 안내 | 엽면살포 전용 | 결과화면 내 섹션 |
| GD-08 | 살포 주기 안내 | 반복 살포 간격(순환 개념 아닌 단순 주기) 안내 | 엽면살포 전용 | 결과화면 내 섹션 |
| GD-09 | 폭염 대응 시점 안내 | 고온기 이전~초기 적용 권장 시점 콘텐츠 | 공통 | 결과화면 하단 **버튼**으로 진입(별도 화면) |
| GD-10 | 자동 살포 설비 연동 가이드 | 점적/분무 디스펜서 등 자동화 설비 사용 시 주의사항(여과·정제로 노즐막힘 방지된 제형이나, 필터 점검 주기 등 안내) | 주로 엽면살포(관주 자동화도 해당 가능) | 결과화면 하단 **버튼**으로 진입(별도 화면, 선택) |

## 4. 확인 필요 사항 (부티릭스 협의)

1. QR코드/제품코드의 실제 규격·발급 방식 (이미 정해져 있는지, 신규 설계 필요한지)
2. 로그인 방식 (자체 계정 vs 소셜 로그인) 및 필수 여부
3. 기상 연계 추천에 사용할 기상 데이터 소스 (공공 API 등) 및 정확도 요구 수준
4. 작물/재배방식별 초기 가이드 콘텐츠 데이터 (희석배수, EC/pH 범위 등) 제공 일정
5. ThermaVita 브랜드 가이드라인(로고, 컬러 코드, 폰트) 유무
6. "ThermaVita Hydro"가 사업계획서상 "ThermaVita"와 동일 제품(수경 시장 대상 정식 제품명)인지 확인 — 사업계획서엔 "Hydro" 표기 자체가 없음, 본 문서 0항은 서비스 설계를 위한 작업 가정
7. "여과·정제(노즐막힘 방지)", "pH/EC 안정성"이 실제 제품 스펙(공인시험 등으로 확인된 값)인지, 목표 사양인지
8. 원료가 "유산균 배양 상등액"(균 제거)인지 "발효액"(균 포함)인지 — 사업계획서 내 표현 간 불일치 확인 필요
9. "재배방식에 따른 희석배수" 문구에서 "재배방식"이 실제로 "적용방법(관주식/엽면살포)"을 의도한 게 맞는지 — 본 문서는 이렇게 해석해 설계함(4번 항목 참조: 예시가 "관주 시"인 것으로 미루어 판단)
10. ThermaVita Hydro가 엽면살포도 지원하는 제품인지, 아니면 관주식 양액공급 단일 방식인지
11. 양액 혼화 방법이 단일 절차인지, 배합 인프라(수동 배합탱크 vs 자동 인젝터/도징펌프)에 따라 여러 절차로 나뉘는지
