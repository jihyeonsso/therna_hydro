# 이벤트 프로시저 기획 — 화면/기능별 확인창·피드백·에러처리

각 화면에서 발생하는 이벤트(제출·삭제·에러 등)에 어떤 절차(확인창/성공피드백/실패처리)가 필요한지 정리.
우선순위: 🔴 필수(데이터 손실·혼란 방지) / 🟡 권장(UX 품질) / ⚪ 선택

---

## A. 제품 연동

| 화면 | 이벤트 | 필요한 절차 | 우선순위 | 상태 |
|---|---|---|---|---|
| QR 스캔 | 카메라 권한 거부 | 안내 문구 + 코드입력 유도 | 🔴 | ✅ 구현됨 |
| QR 스캔 | 인식 성공 | 자동 전환(별도 피드백 불필요) | - | ✅ |
| QR 스캔 | 인식 실패 | 실패 화면(SX-01) 전환 | 🔴 | ✅ 구현됨 |
| 코드 입력 | 빈 값 제출 | 클라이언트 단에서 즉시 막기(현재는 서버에서만 체크) | 🟡 | ❌ `required` 속성 없음 |

## B. 사용 가이드 (작물선택 → 적용방법 → 결과)

| 화면 | 이벤트 | 필요한 절차 | 우선순위 | 상태 |
|---|---|---|---|---|
| 사용법 결과 | "내 작물로 등록" 성공 | 상세화면 진입 시 "등록되었습니다" 1회성 안내 | 🟡 | ❌ 조용히 이동만 함 |
| 사용법 결과 | 이미 등록된 작물 재등록 | "이미 등록되어 있어요"라고 알려주고 기존 카드로 이동 | 🟡 | ⚠️ 기존 카드로는 이동하나 안내 문구 없음 |
| 사용법 결과 | 비로그인 상태에서 등록 클릭 | 로그인 화면 이동(현재 안내 없이 바로 이동) | ⚪ | ⚠️ 동작은 하나 "로그인이 필요해요" 문구 없이 이동 |

## C. 사용 관리 (일정/이력)

| 화면 | 이벤트 | 필요한 절차 | 우선순위 | 상태 |
|---|---|---|---|---|
| 일정 등록/수정 | 저장 성공 | "저장되었습니다" 피드백 | 🟡 | ❌ 없음 |
| **일정 삭제** | 삭제 버튼 클릭 | **"정말 삭제하시겠습니까?" 확인창** | 🔴 | ❌ 없음 — 즉시 삭제됨 |
| 이력 입력 | 저장 성공 | "기록되었습니다" 피드백 | 🟡 | ❌ 없음 |
| 캘린더 | 날짜/월 이동 | 별도 절차 불필요 | - | ✅ |

## D. 마이페이지

| 화면 | 이벤트 | 필요한 절차 | 우선순위 | 상태 |
|---|---|---|---|---|
| 재배환경 등록 | 저장 성공 | "저장되었습니다" 피드백 | 🟡 | ❌ 없음 |
| **회원 탈퇴** | 탈퇴 버튼 클릭 | **확인창 + 실제 탈퇴 로직 자체가 없음** | 🔴 | ❌ 기능 자체 미구현 |
| 로그아웃 | 로그아웃 클릭 | 확인창 필요 여부 — 되돌리기 쉬운 동작이라 보통 생략 | ⚪ | 의도적 생략(적절함) |

| 회원가입 | 실패(중복이메일 등) | 필드별 에러 메시지 | 🔴 | ✅ 최근 구현 완료 |
| 비밀번호 재설정 | 메일 발송 요청 | 실제 발송 로직 자체가 없음 | 🟡 | ❌ 화면만 존재(TODO) |

## F. 관리자 페이지

| 화면 | 이벤트 | 필요한 절차 | 우선순위 | 상태 |
|---|---|---|---|---|
| 제품정보 관리 | 저장 성공 | "저장되었습니다" 피드백 | 🟡 | ❌ 없음 |
| 가이드콘텐츠 관리 | 저장 성공 | "저장되었습니다" 피드백 | 🟡 | ❌ 없음 |
| 공지사항 등록 | 등록 성공 | 피드백 + **입력폼 비우기**(현재 값이 남아있어 실수로 중복등록 위험) | 🟡 | ❌ 없음 |
| **공지사항 삭제** | 삭제 버튼 클릭 | **확인창** | 🔴 | ❌ 없음 — 즉시 삭제됨 |
| **긴급 공지 표시** | `isUrgent=true`로 등록 | 홈 화면에 경고색 배너로 별도 노출 | 🔴 | ❌ DB 필드만 있고 프론트 미반영 (일반 공지와 동일하게 보임) |

## G. 전역(공통)

| 항목 | 필요한 절차 | 우선순위 | 상태 |
|---|---|---|---|
| 예상 못한 서버 에러 | 앱 톤에 맞는 커스텀 에러 화면(`error.tsx`) | 🟡 | ❌ Next.js 기본 에러 화면 노출 |
| 존재하지 않는 페이지(404) | 커스텀 404 화면(`not-found.tsx`) | ⚪ | ❌ Next.js 기본 화면 |
| 세션 만료 후 접근 | 로그인 화면으로 리다이렉트(현재 자동 처리됨) | - | ✅ |
| 온보딩/첫 방문 안내 | 최초 진입 시 간단한 안내 | ⚪ | ❌ 없음(선택사항) |

## 실행 순서 제안

**1차 — 데이터 손실 방지(🔴 중 확인창 관련)**
1. 일정 삭제 확인창
2. 공지사항 삭제 확인창
3. 회원탈퇴 확인창 + 실제 탈퇴 로직 구현
4. 긴급 공지 프론트 반영(경고 배너)

**2차 — 성공 피드백(🟡 저장류 전체)**
5. 저장/등록 성공 시 토스트 또는 배너 (일정, 이력, 재배환경, 제품정보, 가이드콘텐츠, 공지사항)
6. 공지사항 등록 후 입력폼 초기화
7. 작물 재등록 시 안내 문구

**3차 — 전역 에러 처리**
8. 커스텀 에러 화면(error.tsx), 404 화면(not-found.tsx)

**보류(기능 자체가 없어서 순서 의미 없음)**
9. 비밀번호 재설정 실제 발송 로직 — 이메일 인프라 필요, 부티릭스 결정 대기
