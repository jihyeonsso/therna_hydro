# ThermaVita Hydro 앱 — VPS 배포 가이드

대상 서버: Hostinger VPS (Ubuntu 24.04, `srv1925869.hstgr.cloud`)
기존에 traefik(리버스 프록시)이 host 네트워크 모드로 떠 있고, 다른 프로젝트들이 `/docker/<프로젝트명>/docker-compose.yml` 구조로 배포되어 있음. 같은 패턴을 따름.

---

## 1. 사전 준비 (최초 1회)

### 1-1. 서버에 프로젝트 폴더 만들기

```bash
sudo mkdir -p /docker/thermavita-hydro
cd /docker/thermavita-hydro
```

### 1-2. 소스코드 올리기

**방법 A — GitHub 등 git 저장소 사용 (추천)**

로컬(개발 PC)에서:
```bash
git remote add origin <저장소 URL>
git push -u origin main
```

서버에서:
```bash
cd /docker/thermavita-hydro
git clone <저장소 URL> .
```

**방법 B — 파일 직접 전송 (git 안 쓸 경우)**

로컬 PC 터미널에서 (Windows면 WSL/Git Bash에서 실행):
```bash
rsync -avz --exclude node_modules --exclude .next --exclude prisma/dev.db \
  "C:/Users/user/thermavita-hydro-app/" root@<서버IP>:/docker/thermavita-hydro/
```

### 1-3. 환경변수 파일 생성

서버에서:
```bash
cd /docker/thermavita-hydro
cp .env.example .env
```

`.env` 파일을 열어 `SESSION_SECRET`을 무작위 값으로 교체:
```bash
openssl rand -base64 32
```
나온 값을 `.env`의 `SESSION_SECRET=` 뒤에 붙여넣기. (`DATABASE_URL`은 `docker-compose.yml`에서 컨테이너 내부 경로로 별도 지정하므로 `.env`의 값은 로컬 개발용으로만 쓰이고 배포엔 영향 없음 — 그대로 둬도 무방)

---

## 2. 빌드 및 실행

```bash
cd /docker/thermavita-hydro
docker compose up -d --build
```

최초 실행 시 이미지 빌드(1~3분) + 컨테이너 기동 + DB 마이그레이션이 자동으로 진행됩니다.

### 2-1. 초기 데이터 넣기 (선택)

데모 계정/공지사항 등 샘플 데이터가 필요하면:
```bash
docker compose exec app npx tsx prisma/seed.ts
```

---

## 3. 접속 확인

브라우저에서:
```
https://thermavita-hydro.srv1925869.hstgr.cloud
```

- 이 서브도메인은 `docker-compose.yml`의 traefik 라벨에 지정되어 있음. 다른 이름을 쓰고 싶으면 `docker-compose.yml`의 `Host(...)` 부분을 수정.
- Hostinger가 `*.srv1925869.hstgr.cloud` 와일드카드 DNS를 제공하는 것으로 보이므로 별도 DNS 설정 없이 바로 접속되어야 함. **접속이 안 되면** DNS가 와일드카드가 아닐 수 있으니 hPanel에서 해당 서브도메인의 A 레코드를 서버 IP로 직접 추가.
- 첫 접속 시 Let's Encrypt 인증서 발급에 몇 초~수십 초 걸릴 수 있음.

---

## 4. 업데이트(재배포) 방법

코드를 수정한 뒤:

```bash
cd /docker/thermavita-hydro
git pull                      # 방법 A를 쓴 경우
docker compose up -d --build  # 이미지 재빌드 + 컨테이너 교체 (DB 데이터는 volume에 남아있어 유지됨)
```

---

## 5. 데이터 백업

SQLite 파일은 `thermavita_db`라는 Docker volume 안에 있습니다.

```bash
docker run --rm -v thermavita-hydro_thermavita_db:/data -v $(pwd):/backup alpine \
  cp /data/dev.db /backup/dev-db-backup-$(date +%Y%m%d).db
```

---

## 6. 로그/상태 확인

```bash
docker compose logs -f app     # 실시간 로그
docker compose ps              # 컨테이너 상태
```
