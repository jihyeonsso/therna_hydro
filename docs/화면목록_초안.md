## 진행 계획
- 1차 와이어프레임: S-01, S-01b, S-02~S-04, S-04b, S-05, S-05b, S-06a, S-06b, S-08, S-10a/b/d, S-11, S-11b, S-12, S-13, S-15, S-15b, SX-01 (핵심 사용자 흐름 + 필수 예외/법적 화면 + 4개 탭 허브 전부)
- 2차 와이어프레임: S-09, S-10c, S-14, S-15c, A-01~A-05 (부가 기능 + 관리자, 대부분 리스트/폼 패턴이라 저작 속도 빠름)
- 조건부(A-06~A-08): 부티릭스 자료요청서 회신 후 필요 여부 확정, 필요 시 2차에 편입
- UI 디자인 시안은 1차 와이어프레임 승인 후, 임시 브랜드 팔레트로 우선 착수

## 검수 메모 (2차 검토)
과업지시서·기능정의서만 대조했을 때는 드러나지 않았던 항목들을 추가함:
- **법적 요건**: 이용약관/개인정보처리방침(S-10d), 회원탈퇴(S-15c) — 실서비스 운영 시 사실상 필수
- **누락된 입력 폼**: 관주일정 등록폼(S-11b), 재배환경 등록폼(S-15b) — 기능정의서엔 "등록"이라고만 쓰여 있고 그 입력 화면 자체가 화면목록에 없었음
- **예외 처리**: 제품코드 인식 실패(SX-01) — 제품연동은 앱의 핵심 진입 기능인데 실패 케이스가 없으면 와이어프레임 단계에서 놓치기 쉬움
- **인증 플로우 세분화**: 로그인/회원가입/비밀번호재설정을 하나(S-10)로 뭉쳐뒀던 것을 분리

## 검수 메모 (3차 검토 — 적용방법 분기)
"재배방식(관주/엽면살포/수경양액)" 3택 구조가 개념 오류였음을 확인. 수경 양액 시스템 전용 서비스이므로 재배환경 선택은 불필요하고, 실제로 갈리는 축은 **적용방법(관주식 양액공급 / 엽면살포)** 뿐. 이 둘은 필요한 안내 항목 자체가 달라서(EC·pH·순환주기는 관주식 전용) 화면을 분기함:
- S-05(작물선택)와 S-05b(적용방법선택)를 별개 화면으로 분리
- S-06(결과)과 S-07(가이드)을 각각 관주식(a)/엽면살포(b) 버전으로 분리 — 총 4개 화면으로 증가

## 검수 메모 (4차 검토 — 화면 통합)
S-06(결과)과 S-07(가이드)을 분리해 "관련 가이드" 텍스트 링크로 클릭해 넘어가게 한 구조에 대해, 한 적용방법을 선택하면 나오는 정보들(희석배수·사용법·혼화/EC·PH·순환주기 또는 살포방법·살포주기)은 사실상 하나의 "사용법 풀세트"라 화면을 쪼개면 왔다갔다 탐색 비용만 커진다는 피드백 반영. **S-06a/S-07a → S-06a 하나로, S-06b/S-07b → S-06b 하나로 통합**(스크롤 1화면). 주제가 다른 폭염대응·자동살포설비는 계속 별도 화면으로 두되, 텍스트 링크 목록이 아니라 **버튼**으로 하단에 노출.

## 검수 메모 (5차 검토 — 홈 재정의 + 등록작물 플로우)
하단 탭바 중 "홈"이 QR스캔 유도(1회성) 용도로만 쓰이고, 정작 반복 방문 시 확인하고 싶은 "내가 등록한 작물 상태"는 마이페이지에 파묻혀 있던 문제를 확인. **홈을 "등록 작물 대시보드"로 재정의** — 등록작물 카드 리스트(다음 일정 미리보기) + "새 작물 등록"(스캔 진입)을 한 화면에서 처리. 마이페이지는 계정·재배환경 같은 저빈도 설정 전용으로 축소.
- S-01b(작물 상세) 신설 — 카드 클릭 시 사용법 재열람 + 일정/이력 바로가기
- S-06a/S-06b 하단에 "내 작물로 등록" 버튼 추가(GD-11) — 스캔→선택→가이드 플로우의 마지막 단계에서 홈 목록으로 저장
- 기존 S-15b(재배환경 등록)는 유지하되 역할 구분: 재배환경=농장 시스템 프로필(1회성, MY), 등록작물=개별 작물 인스턴스(여러 개, 홈)

## 검수 메모 (6차 검토 — 탭 구조 공백 메우기)
전문가 관점 재검토에서, "탭은 4개인데 실제로 화면이 있는 건 홈뿐"이라는 구조적 공백을 확인 — 각 탭을 눌렀을 때 갈 곳이 없거나(가이드/MY), 탭 안에서 하위 화면끼리 오갈 방법이 없는(관리 내 일정↔이력) 문제였음. 아래로 메움:
- **S-04b(가이드 홈) 신설** — "가이드" 탭 랜딩 화면. 소개 문구 + 작물 그리드, 이후 S-05 이하 흐름 재사용
- **S-15(마이페이지 허브) 신설** — "MY" 탭 랜딩 화면. 프로필카드 + 메뉴 리스트(재배환경/공지사항전체/약관/로그아웃/탈퇴)
- **S-11/S-13(관리)에 상단 세그먼트(일정|이력) 추가** — 두 화면을 오갈 방법이 없던 문제 해결, 각각 FAB로 등록폼/입력폼 진입
- **탭바를 4개 탭-루트 화면(S-01,S-04b,S-11/S-13,S-15) 모두에 일관 적용** — 이전엔 홈에만 있어 다른 탭에서 이동 경로가 검증 안 됐음
- **S-01b(작물상세)**: "일정 등록/보기" 버튼을 상태에 따라 "등록"(일정 없을 때)/"보기"(있을 때)로 조건 분기, 폭염대응 버튼 추가(기존엔 등록 전 플로우에만 있고 재방문 시엔 접근 불가했음)
- **GD-11(내 작물로 등록)**: 비로그인 시 로그인 화면 유도 → 완료 후 복귀 흐름을 문서에 명시(화면 자체는 기존 S-10a 재사용, 신규 화면 없음)
