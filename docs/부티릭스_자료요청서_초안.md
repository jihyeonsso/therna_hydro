# ThermaVita Hydro 사용 가이드 앱 개발 — 자료 요청서 (초안)

- **수신**: 주식회사 부티릭스
- **발신**: 주식회사 에이콘랩
- **관련 과업**: ThermaVita Hydro 제품 연동 사용 가이드 애플리케이션 개발
- **목적**: 과업지시서 2항(과업 범위)에 명시된 사용 정보·제품 정보를 앱에 정확히 반영하기 위해, 아래 항목은 부티릭스가 보유한 고유 정보이므로 확인 및 제공을 요청드립니다.
- **참고**: 과업지시서 4항 "앱에 담기는 사용 정보는 제품 시제품의 실제 사용 조건과 어긋나지 않도록 당사와 맞추어 작성한다"에 근거함.
- **기준 문서 우선순위**: 본 요청서의 항목은 **과업지시서를 1차 기준**으로 구성함. 부티릭스 사업계획서(2026년 지원사업) 등 기타 자료는 참고용으로만 활용했으며, 해당 자료에서 발견된 확인 필요 사항은 각 항목에 "(참고)"로 표시함.

## 1. 제품 기본 정보

| 항목 | 필요 내용 | 비고 |
|------|-----------|------|
| 제품 원료 | ThermaVita Hydro의 주요 원료 성분(유산균 발효액 조성 등, 공개 가능한 수준) | 사용자 화면에 표시할 문구 확인 필요 |
| 원료 형태 (참고) | 원료가 "유산균 배양 상등액"(균 제거)인지 "발효액"(균 포함)인지 | 사업계획서 내 표현이 서로 달라 확인 필요 — 앱 내 원료 설명 문구에 직접 영향 |
| 제품 버전/라인업 | 현재 시제품 버전명, 향후 추가될 제품 버전이 있는지 | 앱 구조(다제품 대응) 설계에 영향 |
| 제품코드/QR 규격 | 제품에 표기될 QR코드 또는 제품코드의 실제 규격(형식, 발급 방식, 이미 인쇄본이 있는지) | 없다면 신규 설계 필요 — 별도 협의 |
| 제형 특성 (참고) | 여과·정제 처리(침전·노즐막힘 방지), pH/EC 안정성이 실제 확정된 제품 스펙인지 | 자동화 설비 연동 가이드 콘텐츠 작성에 필요 |
